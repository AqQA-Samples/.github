## Inside AqQA

AqQA is a local Windows water-chemistry app with a named aqqa desk, a short water list, and a clear last handoff. It does not try to replace the rest of the PC. It sits beside samples you already own and holds only the plot that is open now.
The layout stays small on purpose: one desk, one list, one path back. Extra plots wait for their own title. AqQA starts with a local profile and does not need a complex account system.

The aqqa desk stays on analyses you already keep. Untitled plots stay off the live list.

## Quick Start with AqQA

1. Open the last AqQA session on samples you own, not a new empty plot.
2. Read the aqqa desk and the last handoff.
3. Finish one visible piper view inside AqQA.
4. Write what changed, then close with a shorter water list than you found.
5. If the desk feels crowded, drop anything that belongs to a different analysis.
6. Leave the aqqa desk on samples you already keep.
7. If a plot is not yours, leave it off the live list.
